How this would actually connect. Every figure above is a live read of the same positions/accounts data the trading GUI already uses — this view just adds a privileged, cross-account aggregation layer with its own service credential, separate from any client's login. A bank's risk systems would poll the REST snapshot or subscribe to the WebSocket stream; this page itself would be the reference embeddable widget, built on that same API.
